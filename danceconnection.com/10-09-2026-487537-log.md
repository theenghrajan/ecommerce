## Code changes (line by line)

### 1. NEW file `danceconnection-theme/sections/custom-product-faq.liquid`
The whole file is new. Every line below is an addition (final version, without the temporary debug lines; see 1a).

```liquid
{%- comment -%}
  Product FAQs from metafield custom.ss_product_faqs (list of "faq" metaobjects: question, answer).
  Renders nothing when the product has no FAQs. Markup mirrors sections/faq.liquid.
{%- endcomment -%}
{%- assign faqs = product.metafields.custom.ss_product_faqs.value -%}
{%- if faqs != blank and faqs.count > 0 -%}
  <div class="page-width page-width--narrow">
    {%- if section.settings.title != blank -%}
      <header class="section-header">
        <h2 class="section-header__title">{{ section.settings.title | escape }}</h2>
      </header>
    {%- endif -%}

    <script type="application/ld+json">
      {
        "@context": "https://schema.org",
        "@type": "FAQPage",
        "mainEntity": [
          {%- for faq in faqs -%}
            {
              "@type": "Question",
              "name": {{ faq.question.value | json }},
              "acceptedAnswer": {
                "@type": "Answer",
                "text": {{ faq.answer | metafield_text | json }}
              }
            }{% unless forloop.last %},{% endunless %}
          {%- endfor -%}
        ]
      }
    </script>

    {%- for faq in faqs -%}
      <div>
        <button type="button" class="collapsible-trigger collapsible-trigger--inline collapsible--auto-height text-left" aria-controls="FAQ-content-{{ section.id }}-{{ forloop.index }}">
          {%- render 'collapsible-icons-alt', no_circle: true -%}
          <span>{{ faq.question.value | escape }}</span>
        </button>
        <div id="FAQ-content-{{ section.id }}-{{ forloop.index }}" class="collapsible-content collapsible-content--all">
          <div class="collapsible-content__inner collapsible-content__inner--faq rte">
            {{ faq.answer | metafield_tag }}
          </div>
        </div>
      </div>
    {%- endfor -%}
  </div>
{%- endif -%}

{% schema %}
{
  "name": "Product FAQs",
  "class": "index-section",
  "settings": [
    {
      "type": "text",
      "id": "title",
      "label": "Heading",
      "default": "FAQs"
    },
    {
      "type": "paragraph",
      "content": "Shows the product's FAQs from metafield custom.ss_product_faqs. Hidden when a product has none."
    }
  ],
  "presets": [{ "name": "Product FAQs" }],
  "enabled_on": { "templates": ["product"] }
}
{% endschema %}
```

What each part does:
- `assign faqs` / `if faqs != blank`: reads the product's FAQ list and renders nothing when it's empty.
- `<script type="application/ld+json">`: the FAQPage schema. `name` = question, `text` = answer as plain text (`metafield_text`), so there's no HTML in the JSON.
- `for faq in faqs` block: the visible accordion. The classes (`collapsible-trigger`, `collapsible-content`) and `collapsible-icons-alt` snippet are the ones Impulse already uses in `sections/faq.liquid`, so the existing theme JS/CSS handles open/close. No new JS/CSS.
- `{% schema %}`: "Product FAQs" in the theme editor, one Heading setting, product templates only.
- `faq.question` / `faq.answer` assume the metaobject field keys are `question` and `answer` (not yet confirmed).
