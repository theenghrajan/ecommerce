## Item 1 — Specifications → MIL-DTL-117 → new collection page

1. Admin → **Content → Menus** → open the menu with handle `main-menu-redesign` (the one the header uses).
2. Expand **Specifications** → click **MIL-DTL-117**.
3. In **Link**, clear `/pages/what-to-know-about-mil-dtl-117`, type `MIL-DTL-117`, and pick the **Collection** "MIL-DTL-117" (`/collections/mil-dtl-117`).
4. Keep the label "MIL-DTL-117" → **Done** → **Save menu**.
5. Leave the page `what-to-know-about-mil-dtl-117` as it is. The collection already links to it in "Reading the Code".
6. Check: on the live site, Specifications → MIL-DTL-117 opens `/collections/mil-dtl-117`, and the "What to Know About MIL-DTL-117" link on that page works.

## Item 2 — Hide News & Information → Case Studies

1. In the same menu, expand **News & Information** → hover **Case Studies** → **Delete** (trash icon) → **Save menu**.
2. Keep the page itself. Optional: Online Store → **Pages** → "Packaging Case Studies" → Visibility **Hidden** → Save, so it isn't findable by search or direct link either. Leave it visible if the client only wanted it out of the menu.
3. Check: News & Information shows only Work With Us and FAQs.

## Item 3 — Add "Resources" (menu group for the online tools)

Recommendation: **no new page**. "Resources" is a menu-only parent under News & Information with the three tools nested under it. It works the same way as Products and Specifications, which also link to `#`. The header already renders a hover flyout for third-level items (`snippets/header-main-menu.liquid`), so no theme change is needed.

1. Admin → **Content → Menus** → `main-menu-redesign`.
2. Under **News & Information** → **Add menu item**:
   - Label **Resources**, Link: type `#` → Done.
3. Add the three items, then **drag each one under Resources** so they're nested:
   - **MIL-DTL-117 Flat Bag Size Calculator** → Pages → `mil-dtl-117-flat-bag-size-calculator`
   - **MIL-STD-2073 Desiccant Calculator** → Pages → `mil-std-2073-desiccant-calculator`
   - **Packaging Decoder** → Pages → `packaging-decoder`
4. Order under News & Information (suggested): Resources, Work With Us, FAQs → **Save menu**.
5. Check desktop: hover News & Information → hover Resources → the three tools appear in the flyout, and each link opens the correct page.
6. Check mobile: open menu → News & Information → Resources expands → the three links work.
