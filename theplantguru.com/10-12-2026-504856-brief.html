Disable, don't delete

✓ Disable the size

It disappears from the website. Past orders and reports that include it keep working. Easy to switch back on if Diane changes her mind.

✗ Delete the size

It can't be undone. Past orders lose their link to the product, and re-adding it later means setting it up from scratch.

Process: disable each size in Magento admin

  1. Log in to Magento admin. Get the admin URL and login from Passbolt (The Plant Guru).
  2. Find the product. Go to Catalog → Products and search the product name (e.g. "Menthol Crystals"). Open the main product, the one whose Type is Configurable Product.
  3. Open Configurations. Scroll down to the Configurations section. It lists every size as its own row, with SKU, quantity and status.
  4. Disable the size. On the row for the size, open the Select menu in the Actions column and choose Disable Product. Don't choose Remove Product, because that unlinks it.
  5. Save the product (top right). Wait for "You saved the product."
  6. Repeat for every row in the checklist below.
  7. Clear the cache. Go to System → Cache Management and click Flush Magento Cache. If System → Index Management shows "Reindex required", tell the dev team. It usually clears itself via cron.
  8. Check the site. Open each product link in a private window and open the Size dropdown. The size should be gone, and every other size should still be there.
  9. Take screenshots. Use Awesome Screenshot on the open Size dropdown and draw a red box where the removed size used to be. Use the same order as the checklist.
  10. Hand back to Claude to re-check the site, share the screenshots and draft the completion comment.
Sizes that aren't shown right now (Citric 30/60 lbs, Beeswax 4 lbs) should still appear as rows in Configurations, just with 0 quantity. If a row isn't there, search Catalog → Products for the product name to find the separate size product, open it, switch Enable Product to No and save. If it doesn't exist at all, there's nothing to disable. Note that in the log.
Other way, same result: open the size's own product (click its SKU in the Configurations row, or search the SKU), switch Enable Product to No and save.
